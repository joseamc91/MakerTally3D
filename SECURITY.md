# Security / Seguridad

## English

Security maintenance focuses on the current Android source on `main` and the latest officially distributed Google Play version, when applicable. Report against the latest applicable version. Historical alpha/MAUI tags are unsupported; no long-term support or separate backport schedule is promised.

**Do not disclose sensitive vulnerabilities in public Issues.** Email **joseamc91.dev@gmail.com** with the affected version, Android/device context, impact, description and minimal reproduction steps. Include only information needed to investigate; omit passwords, signing material, personal profiles and unrelated personal data. Ordinary non-sensitive bugs belong in [Issues](https://github.com/joseamc91/MakerTally3D/issues).

Reports are reviewed by the individual maintainer. No response deadline is guaranteed. Coordinate public disclosure after a fix or mitigation can be assessed.

## Español

El mantenimiento de seguridad se centra en el código Android actual de `main` y la última versión distribuida oficialmente en Google Play, cuando corresponda. Informa contra la última versión aplicable. Los tags históricos alpha/MAUI no reciben soporte; no se promete soporte prolongado ni un calendario separado de backports.

**No publiques vulnerabilidades sensibles en Issues.** Escribe a **joseamc91.dev@gmail.com** con versión afectada, contexto de Android/dispositivo, impacto, descripción y pasos mínimos de reproducción. Incluye solo lo necesario; omite contraseñas, material de firma, perfiles personales y datos ajenos al problema. Los errores ordinarios no sensibles van en [Issues](https://github.com/joseamc91/MakerTally3D/issues).

El mantenimiento es individual y no se garantiza un plazo de respuesta. Coordina la divulgación pública después de evaluar una corrección o mitigación.
